# RX NFSU2 Mod Menu

An unofficial userscript for **Need for Speed: Underground 2 Revived**. It provides local career-save editing and in-game helper features.

## Installation
1. Install the Tampermonkey browser extension.
2. Open `RX_NFSU2_Mod_Menu.user.js` and choose **Install**.
3. Visit <https://nfsu2.xyz/> and open your career profile.

## Controls
- **F6:** Open or close the menu.
- **F8:** Hide or show the menu.
